# The Storm Watcher

Real-time space weather monitoring — geomagnetic storm alerts, aurora forecasts, solar wind, and more.

**Live:** [thestormwatcher.com](https://www.thestormwatcher.com)

---

## What it does

Tracks solar and geomagnetic activity in real time and tells you when something interesting is happening in space — or when it might affect you on Earth.

- **Live Kp Index** — real-time geomagnetic activity from NOAA SWPC
- **Geomagnetic Storm Alerts** — G1–G5 storm detection with automatic X notifications
- **Aurora Forecast** — 3-night viewing calendar with cloud cover and sky scoring
- **Aurora Oval** — live visualization on a 3D globe
- **Solar Wind & Bz** — live RTSW data with interactive charts
- **X-ray Flux** — solar flare classification (A/B/C/M/X)
- **ISS Tracker** — live position and pass predictions
- **UV Index & Sun Times** — sunrise, sunset, golden hour, cloud cover
- **AI Assistant** — space weather questions answered in context
- **8 Languages** — EN, BG, ES, FR, DE, RU, ZH, JA

## Data Sources

- [NOAA SWPC](https://www.swpc.noaa.gov/) — Kp index, solar wind, X-ray, aurora oval, storm alerts
- [NASA DONKI](https://kauai.ccmc.gsfc.nasa.gov/DONKI/) — CME and solar flare events
- [GFZ Potsdam](https://kp.gfz.de/) — Kp index (CC BY 4.0)
- [Open-Meteo](https://open-meteo.com/) — cloud cover, UV index, sun times
- [WhereTheISS.at](https://wheretheiss.at/) — ISS position
